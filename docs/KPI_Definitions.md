## Service Cost Analysis

Purpose:
Identify high-cost cloud services and prioritize optimization efforts.

Metrics:

- Total Cost
- Average Cost
- Resource Count
- Average CPU Utilization
- Average Memory Utilization

Business Value:

Helps cloud teams understand which services contribute most to overall cloud spend and where optimization efforts should be focused.


## Region Cost Analysis

Purpose:
Analyze cloud spending and utilization across deployment regions.

Metrics:

- Total Regional Cost
- Average Regional Cost
- Resource Count
- Average CPU Utilization
- Average Memory Utilization

Business Value:

Helps identify high-cost regions, workload distribution patterns, and opportunities for regional optimization.


## Monthly Cost Trend Analysis

Purpose:
Track cloud spending and utilization over time.

Metrics:

- Monthly Cloud Cost
- Monthly CPU Utilization
- Monthly Memory Utilization
- Monthly Resource Count

Business Value:

Provides visibility into spending trends, supports budget planning, and serves as input for AI-based forecasting models.
