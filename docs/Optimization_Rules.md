# Cloud Cost Optimization Rules

## Rule 1

If CPU Utilization < 20% and Memory Utilization < 20%

Recommendation:
Downsize or terminate the resource.

---

## Rule 2

If CPU Utilization > 85% and Memory Utilization > 85%

Recommendation:
Upgrade resource configuration.

---

## Rule 3

If Network Outbound Traffic is unusually high

Recommendation:
Investigate abnormal network activity.

---

## Rule 4

If Usage Duration exceeds predefined threshold

Recommendation:
Review continuously running resources.

---

## Rule 5

If AI detects an anomaly

Recommendation:
Perform manual investigation before optimization.

---

## Rule 6

Generate severity levels using anomaly scores.

- High
- Medium
- Low
