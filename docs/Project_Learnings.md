## Forecasting Feasibility Assessment

The dataset contained cloud usage records across three months (June 2024, July 2024, and August 2024).

Although a monthly trend table was created, the available historical period was insufficient for reliable forecasting model development.

As a result, the AI implementation focused on:

- Resource Efficiency Analysis
- Cost Optimization Recommendations
- Cloud Resource Anomaly Detection

These use cases were better aligned with the available data volume and business objectives.
