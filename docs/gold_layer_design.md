# Gold Layer Design

## Objective

The Gold Layer provides business-ready datasets for cloud cost analysis, optimization recommendations, forecasting, and executive reporting.

## Gold Tables

### 1. gold_cost_summary
Provides organization-level cloud spending KPIs.

### 2. gold_service_cost_analysis
Provides service-level cost and utilization metrics.

### 3. gold_region_analysis
Provides region-wise cloud spending analysis.

### 4. gold_resource_efficiency
Provides resource optimization scoring and recommendations.

### 5. gold_monthly_cost_trend
Provides monthly aggregated data for forecasting models.
